# 基估宝隐私政策

**生效日期：2026年11月24日**  
**最后更新日期：2026年11月24日**

欢迎使用 **基估宝（JiGuBao）**！基估宝是一款面向个人投资者的实时基金估值、重仓股追踪与持仓记账管理工具，涵盖 iOS 客户端、Android 客户端、Web 网页端（[https://jigubao.app](https://jigubao.app)）以及命令行工具（`@jigubao/cli`）。

我们深知个人数据与财务记账信息对您的重要性，并坚持 **“本地优先（Local-First）”与“最小必要收集”** 的隐私保护原则。本隐私政策旨在清晰、透明地向您说明：在您使用基估宝产品与服务期间，我们是否以及如何收集、使用、存储、共享和保护您的信息，以及您享有的查阅、导出、撤回同意与账号/数据删除等权利。

请在使用基估宝前仔细阅读并理解本隐私政策。如您对本政策有任何疑问，可通过本政策末尾的联系方式与我们联系。

---

## 一、核心原则与适用范围

1. **免登录可用（本地优先）**：您可以不注册、不登录账号直接使用基估宝的核心功能（基金搜索、实时估值、重仓股查看、自选与本地持仓管理）。在未登录状态下，您的自选基金、持仓份额、成本、交易记录与界面偏好仅保存在您的设备本地，不会上传至我们的服务器。
2. **仅作信息查询与记账工具**：基估宝仅提供公开市场行情展示与个人持仓记录功能，**不提供**基金或证券买卖交易服务，**不会**要求您提供银行卡号、支付密码、身份证号或券商资金账户登录凭证。
3. **无广告追踪、不出售数据**：我们**不**接入第三方广告 SDK，**不**收集广告标识符（IDFA），**不**跨 App 或跨网站追踪您的行为，也**不会**向任何第三方出售或出租您的个人信息。

## 二、我们收集的信息及使用方式

我们仅在实现具体产品功能所必需的范围内，经您主动操作或明确授权后收集以下信息：

| 信息类型 | 具体内容 | 收集方式 | 使用目的 | 是否必需 |
| :--- | :--- | :--- | :--- | :--- |
| **账号与认证信息** | 电子邮箱地址、登录认证凭据（会话令牌）、会员状态及到期时间 | 仅当您主动注册或登录云同步账号时提供 | 身份验证（邮箱验证码或密码登录）、账号维护、多设备云端同步及 Pro 会员权益识别 | 否（仅云同步/会员功能需要） |
| **个人基金与记账数据** | 自选基金列表、自定义分组、持仓份额与成本、交易流水、定投计划、收益记录及界面偏好设置 | 您在应用内主动录入、导入或配置；仅在登录云同步后上传 | 向您本人展示持仓与收益统计，并在您的多台设备间备份与同步数据 | 否（未登录时仅存本地） |
| **同步设备标识** | 随机生成的设备实例标识、同步时间戳（非广告追踪标识符 IDFA） | 登录云端同步时自动生成 | 识别当前活跃写入设备、检测多设备同步冲突并提示接管，防止数据互相覆盖 | 否（仅云同步功能需要） |
| **持仓截图图片** | 您手动选取的支付宝、天天基金等平台持仓截图 | 仅当您主动点击“截图/OCR 导入”并手动选图时获取 | 通过 OCR 文字识别提取基金代码、份额与成本以快速录入持仓；识别完成后立即丢弃，不做留存 | 否（可选功能） |
| **公开行情查询与基础网络日志** | 查询的基金代码/指数代码、基础网络请求元数据（如 IP 地址、请求时间、状态码） | 应用刷新公开行情或访问接口时产生 | 获取公开基金净值、实时估值与大盘指数，以及保障服务安全稳定与接口防滥用 | 是（联网行情必需） |

### 关键补充说明

- **公开行情查询不含个人隐私**：向行情接口请求基金估值、重仓股或指数数据时，仅传输公开的基金代码或指数代码，不会附带您的账号邮箱或个人持仓明细。
- **截图 / OCR 导入的隐私保护**：在您主动选择使用截图/OCR 导入功能前，系统将向您明确说明用途并请求相册访问授权（或由系统照片选择器仅授权单次选中的图片）。您上传的截图**仅用于当次实时文字识别与持仓解析**，识别结束后即刻从处理内存中释放丢弃，**不会**持久化存储原始图片，**不会**用于 AI 模型训练，也不会用于任何其他用途。

## 三、设备系统权限说明

在 iOS 及移动端使用基估宝时，我们仅按最小权限原则向系统申请以下权限：

| 系统权限 | 使用场景与目的 | 拒绝后的影响 |
| :--- | :--- | :--- |
| **网络访问权限（WLAN / 蜂窝网络）** | 获取实时基金估值、大盘行情及执行可选的云端数据同步 | 无法联网刷新行情与云同步，但不影响已缓存的本地数据查看 |
| **照片图库 / 相册权限（可选）** | 仅在您主动使用“截图/OCR 导入持仓”功能时，供您选择本地持仓截图 | 不影响任何核心功能，您仍可手动录入或通过 JSON 文件导入持仓 |

- **我们不会申请以下权限**：定位（地理位置）、通讯录、麦克风、蓝牙、健康与健身数据、跨 App 追踪权限（App Tracking Transparency / IDFA）。
- 应用内提供的“防息屏模式（保持屏幕常亮）”仅控制前台运行时屏幕不自动休眠，不涉及任何个人数据收集。
- 您可随时在设备系统「设置」中查看或关闭已授予本应用的任何权限。

## 四、第三方服务与数据共享

我们不会与任何无关第三方共享您的个人信息。仅在为您提供云端同步、网络传输与可选 OCR 识别等核心基础能力时，会依托以下合规第三方服务提供方处理必要数据：

1. **Supabase（云端身份认证与数据库服务）**
   - **共享数据类型**：仅在您主动启用云端账号与同步功能时，传输并存储您的邮箱地址、认证信息、同步设备标识及您同步的基金配置与持仓数据。
   - **使用目的**：提供账号注册登录（Supabase Auth）、加密云端存储与多设备同步。
2. **Cloudflare（边缘网络与接口代理服务）**
   - **共享数据类型**：公开基金/指数查询参数及基础网络传输元数据。
   - **使用目的**：优化行情数据请求速度、提供 HTTPS 传输安全与接口防滥用保护。
3. **OCR 文字识别服务提供方（仅在您主动使用截图/OCR 导入时）**
   - **共享数据类型**：仅限您主动选取并提交识别的持仓截图图片。
   - **使用目的**：仅用于即时识别图片中的基金代码、份额及成本文本，不留存图片、不用于模型训练或其他用途。在发送至外部识别服务前，需由您主动触发并确认操作。
4. **公开金融行情数据源（如天天基金、新浪财经等公开行情接口）**
   - **共享数据类型**：仅包含公开的基金代码或大盘指数代码，**不共享**任何用户身份信息或持仓数据。
   - **使用目的**：拉取公开的基金净值、估值、重仓股及市场指数信息。

### 第三方同等保护承诺

我们审慎筛选第三方服务提供方，并要求所有可能接触或处理用户数据的第三方合作伙伴与服务提供方，通过服务条款、数据处理协议（DPA）及严格的安全控制措施，**提供与本隐私政策所述同等或更高标准的用户数据保护**，且严禁其将您的数据用于除向我们提供约定服务以外的任何其他目的。

除上述情形外，我们仅在遵守适用法律法规、法院命令或有权监管机关的合法强制要求时，方可能依法披露必要信息。

## 五、数据存储、安全保护与留存期限

### 1. 存储地点与方式
- **本地存储**：未登录状态下的全部数据，以及登录状态下的本地缓存，存储于您设备的应用本地存储空间中。
- **云端存储**：启用云端同步后，您的账号与同步数据托管于 Supabase 云数据库基础设施（可能涉及跨境云端数据存储与传输）。我们将采取严格的技术与管理措施，确保数据传输与存储符合适用隐私保护标准。

### 2. 安全保护措施
- 全链路通信采用 **HTTPS / TLS** 加密传输，防止数据在传输过程中被窃听或篡改；
- 云端数据库实施**行级访问控制（RLS）与账号身份校验**，确保您的个人持仓与记账数据严格按账号隔离，仅凭您本人的合法身份验证方可访问；
- 认证会话令牌与密码凭证均采用行业标准安全加密与哈希机制处理，我们无法查看您的明文密码。

### 3. 数据留存期限
- **本地数据**：长期保留在您的设备本地，直至您在应用内手动清除数据或卸载基估宝客户端。
- **云端账号与同步数据**：仅在您的账号存续期间保留。一旦您注销账号或提出有效删除申请，我们将永久删除您的账号及全部关联云端数据（法律法规另有强制留存要求的除外）。
- **OCR 截图数据**：仅在即时识别过程中短暂处理，识别完成后立即丢弃，不作任何持久化保留。

## 六、您的权利：管理、撤回同意与账号/数据删除

您对自己的个人数据拥有完全控制权，并可随时行使以下权利：

1. **访问与更正**：您可随时在基估宝应用内查阅、编辑或删除您的自选基金、分组、持仓份额、成本价、交易记录及偏好设置。
2. **数据导出与可携带权**：您可通过应用内的“数据管理”功能，将您的全部基金配置与持仓数据一键导出为标准 JSON 文件进行本地备份或迁移。
3. **撤回授权与停止云同步**：
   - 您可随时在 iOS/Android 系统「设置」中关闭相册等可选系统权限；
   - 您可随时在应用内退出登录以停止云端同步，并继续以纯本地模式使用基估宝；
   - 您可随时在应用内清空本地数据或卸载应用，彻底移除保存在本机的数据。
4. **账号注销与数据永久删除**：
   - **应用内注销**：如您已注册基估宝云端账号，您可在应用内的账号设置页面直接发起账号注销与数据删除操作。确认注销后，您的账号记录及关联的全部云端持仓、分组、交易与配置数据将被**永久删除且不可恢复**（不会以“停用”代替真实删除）。
   - **人工协助删除**：如您在注销过程中遇到问题，或希望直接申请删除与您邮箱关联的全部云端数据，您也可通过本政策「九、联系我们」中的渠道提交申请。我们将在核实您的账号归属后 **7 个工作日内**（最迟不超过 15 个工作日）完成永久删除并向您反馈结果。
   - **温馨提示**：账号删除操作不可逆，建议在注销前先使用导出功能将您的持仓记录备份为本地 JSON 文件。

## 七、未成年人保护

基估宝主要面向具备完全民事行为能力的成年人提供基金信息查询与个人记账工具服务，并非面向未满 14 周岁（或您所在司法辖区适用法律规定的未成年年龄）的儿童设计。我们不会有意收集未成年人的个人信息。

如果您是未成年人的父母或法定监护人，发现未成年人在未经您同意的情况下向我们注册了账号或提供了个人信息，请通过下方联系方式与我们联系，我们将在核实后尽快删除相关信息并注销对应账号。
